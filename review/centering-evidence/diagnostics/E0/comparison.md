# E0 profile comparison (diagnostic-only, pre-downsampled harness)

Each variant edge is inverse-transformed to the normalized coordinates of E0's rendered
900x1200 input and assigned to the nearest base outer edge. `lineDistancePx` is the mean
distance of the transformed endpoints from that base edge line; it is a correspondence
diagnostic, not a detector tolerance. These values are not production-equivalent because E0
does not start from the original HEIC bytes at production resolution and its variants do not
hold the card's working-pixel size constant. Do not tune the detector from this table. REQ-036
defines the replacement raw-HEIC/equalized harness, retained under `../E1/resolution.json`;
this E0 table remains historical localization evidence.
